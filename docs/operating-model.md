# Enterprise Automation Operating Model

## Objective

The purpose of the operating model is to allow infrastructure and platform
engineers to automate quickly while retaining enterprise controls around
identity, runtime, content, targeting, validation, and change execution.

The goal is not CLI versus UI.

The goal is governed execution.
